Regularisation

Machine-learning models should not only perform well on the data used to train them; they should also make good predictions on new, unseen data. A model that learns the training data too closely may suffer from overfitting: it performs very well on training examples but poorly on new examples.

Regularisation is one of the most common techniques for reducing overfitting.

1. From Overfitting to Regularisation

Consider a regression problem in which we want to predict a house price. A simple model might use only its size:

\(f(x) = w_1x + b\)

A more flexible model could introduce polynomial features:

\(f(x) = w_1x + w_2x^2 + w_3x^3 + w_4x^4 + b\)

Adding features makes a model more flexible. This is useful when the relationship is complicated, but an excessively flexible model may adapt to individual training examples rather than capturing the general pattern. The result can be an irregular curve that fits training data extremely well but does not generalise well.

There are several ways to deal with this problem. For a visual introduction, see the accompanying video, addressing overfitting.

More Training Data

If possible, we can collect more examples. With more observations, it becomes harder for a complicated model to adapt to accidental patterns in a small training set. In practice, obtaining additional data may be expensive or impossible.

Fewer Features

Another possibility is to reduce the number of features. A house-price model could include size, bedrooms, floors, age, neighbourhood income, distance from public transport, distance from shops, and many other characteristics. If many features are available but observations are limited, the model may overfit.

Choosing only the most useful features is called feature selection. Its disadvantage is that removing features also removes information that may be useful for prediction.

Regularisation

Regularisation provides another approach. Instead of removing features completely, it keeps them while discouraging them from having excessively large influence.

Regularisation encourages a model to use smaller parameter values, usually producing a simpler model that is less likely to overfit.

2. Penalising Large Parameters

Consider again the polynomial model:

\(f(x) = w_1x + w_2x^2 + w_3x^3 + w_4x^4 + b\)

Suppose the \(x^3\) and \(x^4\) terms make the model unnecessarily complicated. Removing those features is equivalent to setting \(w_3 = 0\) and \(w_4 = 0\).

Regularisation takes a softer approach. Rather than forcing these parameters to zero, it encourages them to be small. If the original cost function is \(J(w,b)\), we could modify it to include:

\(J(w,b) + 1000w_3^2 + 1000w_4^2\)

If \(w_3\) or \(w_4\) becomes large, the added terms become large too. Because the learning algorithm minimises the cost function, it has an incentive to keep these parameters small. The corresponding features remain present, but their effect becomes weaker.

Usually we do not know beforehand which parameters should be small, so we normally penalise all weights \(w_1, \ldots, w_n\).

3. The Regularised Cost Function

For linear regression, the ordinary squared-error cost is:

\(J(w,b) = \frac{1}{2m}\sum_{i=1}^{m}(f_{w,b}(x^{(i)}) - y^{(i)})^2\)

With regularisation, we add another term:

\(J(w,b) = \frac{1}{2m}\sum_{i=1}^{m}(f_{w,b}(x^{(i)}) - y^{(i)})^2 + \frac{\lambda}{2m}\sum_{j=1}^{n}w_j^2\)

The second part, \(\frac{\lambda}{2m}\sum_{j=1}^{n}w_j^2\), is the regularisation term. The symbol \(\lambda\), pronounced lambda, is the regularisation parameter.

The new cost function has two objectives:

  1. Fit the training data well by keeping prediction errors small.
  2. Keep the model relatively simple by preventing weights from becoming unnecessarily large.

The role of \(\lambda\) is to determine how strongly we care about the second objective. This construction is developed visually in the accompanying video on the regularised cost function.

4. What Does Lambda Do?

The value of \(\lambda\) controls the strength of regularisation.

If \(\lambda = 0\)

When \(\lambda = 0\), the regularisation term disappears. We are back to the original learning algorithm, and a highly flexible model may overfit.

If \(\lambda\) Is Very Large

If \(\lambda\) is extremely large, the algorithm strongly penalises weights that differ from zero. It will try to make nearly all weights small:

\(w_1 \approx w_2 \approx \cdots \approx w_n \approx 0\)

For linear regression, \(f(x) = w_1x_1 + \cdots + w_nx_n + b\), the prediction becomes approximately \(f(x) \approx b\). The model may become too simple and underfit the data.

Choosing a Useful Value

We want neither extreme: too little regularisation can lead to overfitting, while too much can lead to underfitting. A suitable value of \(\lambda\) balances fitting training data with keeping the model simple. Choosing hyperparameters such as \(\lambda\) systematically is part of model selection.

6. Why Is b Usually Not Regularised?

The regularisation term contains \(w_1, w_2, \ldots, w_n\), but not the intercept \(b\):

\(\frac{\lambda}{2m}\sum_{j=1}^{n}w_j^2\)

It is normally used instead of \(\frac{\lambda}{2m}(\sum_{j=1}^{n}w_j^2 + b^2)\). This is mainly a convention; regularising \(b\) usually makes little practical difference.

We normally regularise the weights \(w_j\), but not the intercept \(b\).

7. Regularised Linear Regression

Regularisation can be incorporated directly into gradient descent. Recall the ordinary update:

\(w_j := w_j - \alpha\frac{\partial J}{\partial w_j}\)

For regularised linear regression, the derivative with respect to \(w_j\) becomes:

\(\frac{\partial J}{\partial w_j} = \frac{1}{m}\sum_{i=1}^{m}(f_{w,b}(x^{(i)}) - y^{(i)})x_j^{(i)} + \frac{\lambda}{m}w_j\)

Therefore:

\(w_j := w_j - \alpha[\frac{1}{m}\sum_{i=1}^{m}(f_{w,b}(x^{(i)}) - y^{(i)})x_j^{(i)} + \frac{\lambda}{m}w_j]\)

Because \(b\) is not regularised, its update remains unchanged. The important point is that regularisation adds a term proportional to \(w_j\), encouraging weights to become smaller. The accompanying video on regularised linear regression shows this modification in gradient descent.

Optional: Weight Decay Interpretation

The update can be rearranged approximately as:

\(w_j := (1 - \alpha\frac{\lambda}{m})w_j - \alpha(\text{ordinary gradient})\)

Normally, \(0 < 1 - \alpha\frac{\lambda}{m} < 1\). At each iteration, the current weight is multiplied by a number slightly smaller than one, so weights are gradually shrunk. This is also called weight decay.

8. Regularised Logistic Regression

Regularisation is not limited to linear regression. Logistic regression uses \(f_{w,b}(x) = \sigma(w \cdot x + b)\), where:

\(\sigma(z) = \frac{1}{1 + e^{-z}}\)

A logistic-regression model can overfit, particularly when there are many features or high-order polynomial features. In two-dimensional classification, this may appear as an unnecessarily complicated decision boundary that twists around individual training examples.

To regularise logistic regression, we add the same regularisation term, \(\frac{\lambda}{2m}\sum_{j=1}^{n}w_j^2\), to its usual cost function. This discourages excessively large weights. The gradient becomes:

\(\frac{\partial J}{\partial w_j} = \frac{1}{m}\sum_{i=1}^{m}(f_{w,b}(x^{(i)}) - y^{(i)})x_j^{(i)} + \frac{\lambda}{m}w_j\)

The expressions for regularised linear and logistic regression look almost identical. The important difference is the definition of \(f_{w,b}(x)\): linear regression uses a linear function, while logistic regression applies the sigmoid function. 9. Regularisation Does Not Simply Mean Smaller Is Always Better

Because regularisation makes weights smaller, it may be tempting to always use very strong regularisation. This is incorrect. The objective is not to make weights as small as possible; it is to build a model that generalises well.

Regularisation creates a trade-off: fit the data versus keep the model reasonably simple. Too little may leave an overly complicated model, while too much may prevent the model from learning important relationships.

Broader principle: increasing model complexity can improve the fit to training data, but excessive complexity may reduce performance on unseen data.

10. Regularisation and Feature Selection

Regularisation and feature selection are related but should not be confused. If a model has the feature \(x_j\), feature selection might remove \(x_j\) completely, effectively forcing \(w_j = 0\).

The regularisation introduced here instead encourages \(w_j\) to be small. It retains information from many features while limiting how strongly individual features influence the model. This is useful when many features may be relevant and we do not know in advance which should be removed.

11. A Small Conceptual Example

Imagine predicting student performance using 50 variables with a dataset of only 120 students. A sufficiently flexible model might discover accidental relationships such as:

  • a particular room number being associated with higher grades;
  • a particular day of data collection appearing unusually important;
  • one uncommon combination of attributes strongly influencing the prediction.

These patterns may occur in the training data but have little value for future students. Regularisation discourages the model from assigning extremely large weights to such relationships unless the data provides strong evidence that they are useful. The result is often a more stable model that performs better on new observations.

12. What You Should Remember

  • Complex models are more susceptible to overfitting, especially when training data is limited.
  • Responses to overfitting include collecting more data, selecting fewer features, and regularisation.
  • Regularisation keeps available features but discourages excessively large parameters.
  • It adds \(\frac{\lambda}{2m}\sum_{j=1}^{n}w_j^2\) to the original cost function.
  • \(\lambda\) controls the strength of regularisation.
  • A very small \(\lambda\) provides little protection from overfitting; a very large \(\lambda\) can cause underfitting.
  • We normally regularise \(w_1, \ldots, w_n\), but not \(b\).
  • The same idea applies to linear and logistic regression.
Regularisation asks the learning algorithm not only to fit the training data, but also to prefer solutions that do not rely on unnecessarily large parameter values.

This usually produces a simpler, smoother model that is less sensitive to peculiarities of training data and has a better chance of generalising to unseen examples.
